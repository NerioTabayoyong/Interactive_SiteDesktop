Reflections

I determined that any site elements that needed to be customizable or and to fit a format needed to be a flex element. Things such as text, images, headers, etc. Applying the code display: flex turns the container element into a flex item. Allowing for anything within its category to be easily edited. From arranging how an element is formatted, it's alignment, and distributing space between elements by changing margin and padding.

There are two projects that come to mind that I’d say helped better understand this project. One of them being the mid century blog assignment. That project in general helped me better understand CSS coding and altering elements as a whole. Drilling the idea in my head that elements need room to breathe and have to be spaced out. But the most important module was the box model project. That helped paint a clearer image in my head that every element can be fit into a square that can be altered. No matter how large or how much CSS code is used within an element it’s boxed in via a square. The elements to a page are all building blocks that contribute together to form a coherent website.
