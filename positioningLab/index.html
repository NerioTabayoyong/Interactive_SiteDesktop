positioning elements

Static

default, as-is behavior

Relative

this positions a child relative to its parent. by giving an element a relative position, we can place it outside the normal flow of where it would be- but it still impacts other elements

Absolute

this takes the element out of the line up and no longer impacts elements around it, BUT you have to apply position:relative to a parent container

Fixed

positioned in relation to the browser window, it just stays put!

***Sticky***

this one is a little more advanced, and we won’t get into it yet, but perhaps challenge yourself and your project to see if you can figure it out?


Next up: z-index

this is how we control layering when we are using positioning. if an element has a position, you can add a z-index, the larger the number the closer to the top.
0=bottom 100=top
think of z-index like the “bring to front” or “send to back” in design software.

Reflection

Positioning fixed made the most sense to me. It fixes an element to whatever location you assign it to. That’s what happened with the footer element. We were required to lock the footer to the bottom right of the screen and as a result it stayed there even while scrolling up and down the site. From what I can understand, using ‘Position: Relative;’ positions an element relative to its normal position in the document flow. Occupying it's original space within the website's layout. ‘Position: Absolute’ causes this to be ignored by other elements surrounding it. Essentially making it an overlay and positions said element next to its closest positioned ancestor.

The Z-Index element controls the stacking of elements on the site. Determining whether an element appears over or under an element. If the Z-Index element has a high number than it will be on top. A lower or even a negative number causes the element to appear behind within the imaginary Z-Axis. While useful for creating overlays or keeping important elements on top no matter what. Overuse of position elements can create problems such as a cluttered website that messes with the natural hierarchy. From my own testing it’s best to use positioning in moderation and only on certain elements.
